# Git 推送技能

将当前工作目录的代码变更提交并推送到 GitHub 远程仓库 `ikun5200/ds2api` 的 `main` 分支。

## 执行步骤

1. 运行 `git status` 查看当前变更状态
2. 运行 `git add -A` 暂存所有变更
3. 根据变更内容生成简洁的中文提交信息，格式为：`<简要描述变更内容>`
4. 运行 `git commit -m "<提交信息>"` 提交变更
5. 运行 `git push` 推送到远程仓库

## 提交信息规范

- 使用中文描述变更内容
- 简洁明了，一句话概括
- 根据实际修改的文件自动推断提交信息

## 注意事项

- 如果推送被拒绝（远程有新提交），先执行 `git pull --rebase origin main`，解决冲突后再推送
- 如果没有变更，告知用户"没有需要推送的变更"
- 不要使用 `--force` 推送，除非用户明确要求
